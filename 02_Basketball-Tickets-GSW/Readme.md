# Case Study 2: Optimizing basketball tickets for the golden state warriors.

## Introduction:
The goal of this project is to utilize a multi-task learning model to try and predict 2 different labels:
- The number of days before the game a cusomer purchases the ticket.
- An overall category of when the customer will purchase the ticket: Last-Minute, Planner, or In-Between.

## Files:
- Eda.ipynb
A general purpose eda notebook that contains visualizations for basic data investigations.  Not modeling was done here it serves to validate MTL model hypothesis.
- model-design.ipynb
Testing individual models to see which base model perfomes the best out of the standard base models.
- multi-task-model.ipynb
A class design for the multi task model network architecture.  In depth description of the model architecture exists within the notebook.
